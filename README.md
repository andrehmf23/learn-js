## info
### Sequencia
1. Browser pede HTML
2. HTML é parseado
3. DOM é criado
4. CSS é baixado
5. CSSOM é criado
6. DOM + CSSOM = Render Tree
7. Layout (posição dos elementos)
8. Paint (desenha pixels)
9. JS executa e pode alterar tudo

### Protocolo
